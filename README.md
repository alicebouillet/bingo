# 🚗 KiVoitQuoi

**Le bingo du road trip !** Une application web interactive pour rendre vos trajets en voiture plus amusants, surtout avec des enfants.

## 📋 Description

KiVoitQuoi est un jeu de bingo interactif conçu pour les voyages en voiture. Repérez des éléments sur la route (camions, vaches, châteaux d'eau, panneaux...) et cochez-les sur votre grille pour gagner !

## ✨ Fonctionnalités

### 🎮 Modes de jeu
- **Mode Équipe** : Une seule grille partagée par tous les joueurs
- **Mode Défi** : Chaque joueur a sa propre grille pour se défier

### 🎯 Options de jeu
- **3 niveaux de difficulté** : Facile, Moyen, Difficile
- **1 à 4 joueurs** avec noms personnalisables et couleurs différentes
- **Grille personnalisable** : Choisissez vos 25 éléments ou laissez le hasard décider
- **Éléments personnalisés** : Ajoutez vos propres éléments avec emojis

### 🏆 Fonctionnalités avancées
- **Détection automatique de BINGO** avec animation de confettis
- **Historique des parties** sauvegardé localement
- **Partage QR Code** : Partagez la même grille avec d'autres appareils
- **Mode impression** : Imprimez des grilles papier (1-8 grilles)
- **Progressive Web App** : Installable sur mobile et utilisable hors ligne

### 🎨 Interface
- Design coloré et chaleureux inspiré des road trips
- Animations fluides et interactions tactiles optimisées
- Compatible mobile, tablette et desktop
- Thème "Road Trip Soleil" avec décorations (nuages, montagnes)

## 📱 Utilisation

### Démarrer une partie

1. **Choisissez un mode** : Équipe ou Défi
2. **Configurez la partie** :
   - Nombre de joueurs (1-4)
   - Prénoms des joueurs
   - Difficulté (Facile/Moyen/Difficile)
   - Type de grille (Aléatoire/Personnalisée)
3. **Cliquez sur "C'est parti !"**

### Pendant le jeu

- **Cochez les cases** : Tapez sur une case quand vous voyez l'élément
- **BINGO !** : Une ligne complète (horizontale, verticale ou diagonale) = BINGO
- **Changez de grille** : Utilisez les boutons pour réinitialiser ou générer une nouvelle grille
- **Partagez** : Utilisez le QR code pour partager la grille avec d'autres appareils

### Éléments personnalisés

1. Allez dans **"Mes éléments"** depuis l'accueil
2. Choisissez un emoji et entrez un nom
3. Vos éléments s'ajoutent automatiquement au pool de jeu

## 🎲 Éléments du jeu

Plus de 40 éléments à repérer sur la route :

**Faciles** : Camion, vaches, station essence, tracteur, moutons, pont, voiture de police...

**Moyens** : Château d'eau, tournesols, tunnel, éolienne, arc-en-ciel, camping-car...

**Difficiles** : Château, hélicoptère, centrale électrique, prison, barrage, accident, convoi exceptionnel...

**Élément légendaire** 💀 : 2 châteaux d'eau côte à côte !

## 🖨️ Impression

L'application permet d'imprimer des grilles papier :
- Choisissez la difficulté
- Sélectionnez le nombre de grilles (1-8)
- Cliquez sur "Imprimer maintenant"
- Parfait pour les enfants qui préfèrent le papier !
